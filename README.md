📱 راهنمای کامل SepehrSky OS 26 Ultra

مقدمه

SepehrSky OS 26 Ultra یک سیستم‌عامل شبیه‌سازی‌شده مبتنی بر وب است که تجربه‌ای مدرن و چندوظیفه‌ای را در مرورگر شما ارائه می‌دهد. این پروژه با الهام از رابط‌های کاربری موبایل و دسکتاپ طراحی شده و قابلیت‌های متنوعی را در اختیار شما قرار می‌دهد.

---

🚀 شروع سریع

راه‌اندازی اولیه

1. فایل Sepehr Sky os v26.html را در مرورگر خود باز کنید
2. انیمیشن بوت ۳۰ ثانیه‌ای را مشاهده خواهید کرد
3. پس از بوت، ویزارد راه‌اندازی نمایش داده می‌شود

مراحل ویزارد راه‌اندازی

مرحله توضیحات تنظیمات
۱ انتخاب زبان فارسی (RTL) / انگلیسی (LTR)
۲ شخصی‌سازی نام کاربری، نام دستگاه، آواتار
۳ امنیت قفل PIN (۴ رقمی) / باز کردن مستقیم
۴ ظاهر و عملکرد تم رنگی، حالت عملکرد (Ultra/Balanced/Battery Saver)
۵ نهایی‌سازی نمایش پیشرفت راه‌اندازی سیستم

🎮 دستورات ترمینال

دستور توضیحات
help نمایش لیست دستورات
clear پاک کردن صفحه ترمینال
ls نمایش محتویات سیستم فایل
reboot راه‌اندازی مجدد سیستم

🔧 پنل‌های کنترلی

۱. مرکز کنترل (Control Center)

· فعال‌سازی: کلیک روی نوار وضعیت بالا
· امکانات: وضعیت Wi-Fi، بلوتوث، حالت تاریک، حالت عملکرد

۲. پنل لبه (Edge Panel)

· فعال‌سازی: کلیک روی نوار باریک سمت راست صفحه
· امکانات:
  · 🔄 راه‌اندازی مجدد سیستم
  · 🛠 حالت ریکاوری
  · ⇩ حالت دانلود (Odin)
  · ⏻ خاموش کردن دستگاه

---

🛠 حالت ریکاوری (Recovery Mode)

برای ورود به حالت ریکاوری:

1. از پنل لبه گزینه Recovery را انتخاب کنید
2. یا از منوی اپلیکیشن‌ها روی Recovery کلیک کنید

گزینه‌های ریکاوری:

گزینه عملکرد
🔑 قفل بوت‌لودر قفل/بازکردن بوت‌لودر
۱. راه‌اندازی مجدد بازگشت به سیستم
۲. حالت دانلود ورود به حالت Odin
۳. تشخیص سخت‌افزار تست لمسی و گرافیک
۴. بازنشانی کارخانه پاک کردن تمام داده‌ها
۵. تعمیر VFS تعمیر سیستم فایل
۶. خاموش کردن خاموش کردن دستگاه

---

📥 حالت دانلود (Odin Mode)

برای نصب اپلیکیشن‌های سفارشی:

نصب بسته ZIP

```bash
1. وارد حالت Odin شوید
2. فایل ZIP حاوی اپلیکیشن را انتخاب کنید
3. سیستم بسته را پردازش می‌کند
```

نصب فایل HTML

```bash
1. در حالت Odin، فایل HTML را انتخاب کنید
2. اپلیکیشن به لیست برنامه‌ها اضافه می‌شود
```
